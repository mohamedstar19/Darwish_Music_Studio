# Darwish Music Studio

> ذكريات عايشة جوانا... وأغاني عمرها ما بتنسينا
> Your Memories. Your Music. Your Universe.

منصة موسيقى عربية لشارات الكرتون والأنمي وأغاني التسعينات والألفينات: مكتبة حسب الطلب، محطات راديو مباشرة،
مشغل مستمر، قوائم تشغيل، ولوحة إدارة فيها إدارة الحقوق ولوحة "مباشر" لمين أونلاين وبيسمع إيه.

وثيقة الرؤية الأصلية: [docs/Project_Plan.md](docs/Project_Plan.md)

## المميزات

**للمستمع**
- مكتبة بالتصنيف والعمل (الكرتون/الأنمي) والفنان، وبحث عربي ذكي (أ/ا/إ، ة/ه، ى/ي، والتشكيل كله واحد).
- مشغل مستمر أثناء التنقل، قائمة انتظار، عشوائي وتكرار، تحكم من شاشة القفل وسماعات البلوتوث، وبيكمل من مكانه بعد إعادة التحميل.
- **راديو مباشر "متزامن"**: كل اللي فاتحين المحطة بيسمعوا نفس الأغنية في نفس الثانية، بدون Icecast، مع عدد المستمعين، اللي اتذاع واللي جاي، وطلبات الأغاني والإهداءات.
- **خمّن الشارة**: لعبة بتشغل أول 8 ثواني من شارة وإنت تخمن العمل.
- **آلة الزمن**: تصفح بالسنة أو العقد، و"فاجئني من الفترة دي".
- **ذكرياتي**: ملخص شخصي (أكتر أغاني وأعمال وتصنيفات، وقت الاستماع، بتسمع إمتى في اليوم).
- فاجئني بأغنية، مؤقت النوم مع خفوت تدريجي، وضع السيارة، ثيم ليلي/نهاري/ريترو.
- تطبيق قابل للتثبيت (PWA) على الموبايل والكمبيوتر.
- المفضلة، قوائم تشغيل خاصة وعامة قابلة للمشاركة، سجل استماع مع تحكم كامل في الخصوصية.

**للإدارة**
- رفع جماعي بالسحب والإفلات. السيرفر بيحول كل ملف لـ MP3 بصوت موحّد (loudness normalization)، ويقرا الاسم والمدة والغلاف من الملف.
- **الحقوق جزء من البيانات**: نوع الحقوق، المصدر، النطاق (استماع/راديو/تنزيل/تجاري)، المناطق، تاريخ الانتهاء. مفيش نشر لأغنية حقوقها "قيد المراجعة"، والأغنية بتختفي لوحدها لما الترخيص ينتهي.
- **مباشر**: مين أونلاين دلوقتي، كل مستخدم بيسمع إيه وعلى أنهي محطة، الأجهزة، عدد تثبيت التطبيق، عدد التنزيلات، الزوار.
- إحصائيات: تشغيل يومي، استهلاك البيانات، الأكثر استماعًا، تراخيص قربت تنتهي، أخطاء التشغيل.
- إدارة الأعمال والتصنيفات والفنانين والمحطات (تخطي الأغنية للكل)، طلبات الأغاني، البلاغات، المستخدمين والأدوار (مستخدم/محرر/مدير).

## التقنيات

| الجزء | التقنية |
|---|---|
| الواجهة | React 19 + Vite (عربي RTL، PWA) |
| الـ API | Node.js 22 + Fastify 5 |
| قاعدة البيانات | PostgreSQL 17 |
| معالجة الصوت | ffmpeg (loudnorm → MP3) |
| التشغيل | Docker Compose |
| النشر للعامة | Cloudflare Tunnel على `dms.darwish-tech.com` |

## التشغيل على السيرفر (192.168.1.116)

```bash
git clone https://github.com/mohamedstar19/Darwish_Music_Studio.git
cd Darwish_Music_Studio
cp .env.example .env
nano .env          # غيّر كل كلمات السر (openssl rand -hex 32)
./scripts/deploy.sh
```

الموقع هيبقى على `http://192.168.1.116:8095`. أول دخول بحساب `ADMIN_EMAIL` / `ADMIN_PASSWORD` اللي في `.env`.

أي تحديث بعد كده: `./scripts/deploy.sh` (بيعمل `git pull` ويبني ويشغل).

### الدومين dms.darwish-tech.com

الدومين على Cloudflare، فأسهل وأأمن طريقة هي Cloudflare Tunnel (من غير فتح بورتات على الراوتر):

1. Cloudflare Zero Trust → Networks → Tunnels → Create tunnel → انسخ الـ token.
2. Public hostname: `dms.darwish-tech.com` → Service: `http://app:8080`.
3. في `.env`: `CLOUDFLARE_TUNNEL_TOKEN=...` و `COOKIE_SECURE=true`.
4. `./scripts/deploy.sh` (بيشغل cloudflared تلقائيًا لما يلاقي الـ token).

لو عندك tunnel شغال بالفعل على السيرفر، ضيف الـ hostname ليه ووجهه على `http://192.168.1.116:8095`.

### النسخ الاحتياطي

```bash
BACKUP_DIR=/mnt/truenas/dms-backups ./scripts/backup.sh
```

بيعمل dump لقاعدة البيانات ويزامن ملفات الصوت. حطه في cron يوميًا (التفاصيل جوه السكريبت).

## التطوير محليًا

```bash
docker compose up -d db          # أو أي PostgreSQL
cd server && npm install && DATABASE_URL=postgres://... JWT_SECRET=dev npm run dev
cd web && npm install && npm run dev   # http://localhost:5173
```

## هيكل المشروع

```
server/            Fastify API
  migrations/      SQL migrations (بتتطبق تلقائيًا عند التشغيل)
  src/routes/      auth, catalog, library, radio, quiz, admin
  src/radio.js     الراديو المتزامن
  src/media.js     الرفع ومعالجة الصوت
  src/presence.js  مين أونلاين وبيسمع إيه
web/               React app
  src/admin/       لوحة الإدارة
  src/pages/       صفحات المستمع
  src/state/       المشغل، الحساب، الحضور
scripts/           deploy.sh, backup.sh
```

إن ليك حق نشره. ارفع المحتوى المحمي كـ "قيد المراجعة" لحد ما الترخيص يكتمل.
